    Android Studio et gestionnaire de ressources¶

    13.1 Les raccourcis-clavier d'Android Studio¶

    Puisque Android Studio est basé sur IntelliJ, plusieurs raccourcis-clavier utilisés par les habitués de Jetbrains sont disponibles dans Android Studio.

    Voici les principaux raccourcis-clavier que vous utiliserez lors de vos séances de programmation.

    Recherche¶

    Raccourci Windows Rôle Équivalent Mac
    Ctrl + Maj + N Rechercher un nom de fichier dans tout le projet ⌘ Cmd + ⇧ Maj + O
    Ctrl + E Ouvrir rapidement un fichier déjà consulté ⌘ Cmd + E
    Ctrl + Maj + F Rechercher partout (un menu, une action, un symbole) ⌘ Cmd + ⇧ Maj + F
    Ctrl + F Rechercher un mot dans le document actif ⌘ Cmd + F
    ⇧ Maj - ⇧ Maj Rechercher partout (un menu, une action, un symbole) ⌘ Cmd + ⇧ Maj + F
    Ctrl + N Rechercher une classe dans tout le projet ⌘ Cmd + O
    Ctrl + Maj + N :numéro Rechercher un nom de fichier dans tout le projet ou l'ouvrir directement à la ligne demandée ⌘ Cmd + ⇧ Maj + O
    ⌘ Cmd + ⇧ Maj + F7 (selon le clavier, peut nécessiter la touche Fn pour accéder aux touches de fonction) Mettre en surbrillance toutes les occurrences d'un mot dans la page actuelle Ctrl + Maj + F7
    Ctrl + Maj + F7 Rechercher une option de menu ou une action de la barre d'outils ⌘ Cmd + ⇧ Maj + A
    Ctrl + Maj + Alt + N Rechercher un symbole. Utile pour retrouver une méthode par son nom ⌘ Cmd + ⇧ Maj + A

    Commentaires¶

    Raccourci Windows Rôle Équivalent Mac
    Ctrl + / Mettre en commentaire ou enlever les marques de commentaires ⌘ Cmd + / (selon le clavier, pourrait être plutôt ⌘ Cmd + É)

    Édition¶

    Raccourci Windows Rôle Équivalent Mac
    Ctrl + Espace Complétion de code (fonctionne dans l'édition d'un fichier et dans la zone de recherche) ⌃ Ctrl + Espace
    Ctrl + Maj + Entrée Complétion d'une instruction comme if, while, try-catch, etc. ⌘ Cmd + ⇧ Maj + ↵ Entrée
    Ctrl + Y Supprimer une ligne ⌘ Cmd + ⌫ Retour arrière
    Ctrl + D Dupliquer une ligne ⌘ Cmd + D
    Shift + Alt + Flèche haut/bas Déplacer une ligne ⇧ Maj + ⌥ Option + Flèche haut/bas
    Ctrl + Alt + L Refaire l'alignement du code (reformat) ⌘ Cmd + ⌥ Option + L
    Ctrl + W Étendre la sélection .
    Ctrl + Alt + Maj + Sélection Sélectionner une colonne sur plusieurs lignes ⌥ Option + ⇧ Maj + Sélection
    (sélection rectangulaire) Sélectionner une zone de texte .
    Ctrl + Alt + V Extraire le code sélectionné pour en faire une variable .
    Ctrl + Alt + M Extraire le code sélectionné pour en faire une méthode .
    Ctrl + Maj + V Coller à partir d'une sélection précédente .
    ⌘ Cmd + ⇧ Maj + F7 (selon le clavier, peut nécessiter la touche Fn pour accéder aux touches de fonction) Afficher tous les endroits où une classe, une méthode ou une fonction est utilisée dans le projet (find in usages) Alt + F7
    Alt + F7 Sélectionner la prochaine occurrence du mot actuellement sélectionné, créant une sélection multiple ⌃ Ctrl + G
    Alt + Clic Sélectionner la prochaine occurrence du mot actuellement sélectionné, créant une sélection multiple ⌥ Option + Clic
    ⌘ Cmd + B ou ⌘ Cmd + Clic Atteindre la définition d'une méthode .
    Alt + Entrée Afficher la définition d'une méthode dans un popup ⌥ Option + ↵ Entrée
    Ctrl + Maj + Retour arrière Place le curseur à la dernière ligne où une modification a été effectuée, sans défaire cette modification .
    Ctrl + P Lorsque le curseur est entre les parenthèses de l'appel d'une fonction, affiche les paramètres à entrer .
    Ctrl + Maj + J Joindre les lignes sélectionnées et enlever les espaces superflus (Smart Line Join) ⌃ Ctrl + ⇧ Maj + J
    Ctrl + Alt + T Entourer le code sélectionné à l'aide d'une structure de code suggérée par PhpStorm selon le contexte .
    Ctrl + Alt + J Entourer le code sélectionné à l'aide d'un Live Template .
